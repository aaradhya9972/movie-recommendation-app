      What happens when you type a movie name?

      1. Autocomplete. Every keystroke calls /api/search. The backend normalises text (lower-case, strip punctuation), scores exact / prefix / substring matches and falls back to difflib fuzzy matching, so “incepshun” still finds Inception.
      2. Resolve. The title becomes a movie_id → a row index in the matrices.
      3. Content-based score. Each movie is a text document: genres ×3 + keywords + decade. TF-IDF turns it into a vector (rare words weigh more). Cosine similarity between the query vector and all 3,700 movies gives a content score.
      4. Collaborative score. The sparse user × movie matrix (1M ratings) is mean-centred per user (so a harsh and a generous user are comparable). The adjusted-cosine similarity of the query’s rating column against all other columns says “people who rated this like that, also rated those like this”. A shrinkage factor n/(n+25) lowers trust in pairs with few common raters.
      5. Hybrid blend. score = α·content + (1−α)·collaborative. This fixes the weaknesses of each: content-only can’t see taste, CF-only fails on new/rare movies (cold start).
      6. Filter & rank. Remove the query movie, apply genre / year filters, add a mild popularity prior, sort, take top-N.
      7. Explain. For each result the API returns shared genres & keywords, content % and collaborative % — shown on the cards and in the “Behind the scenes” panel with timings.

      Matrix factorisation (SVD / ALS)

      Every user u and movie i gets a short vector of k=20 hidden “taste” factors. The predicted rating is

      r̂ui = μ + bu + bi + pu · qi

      μ = global mean, bu = how generous the user is, bi = how good the movie is, p·q = how well this user’s taste matches this movie. Vectors are learned by Alternating Least Squares — fix movies, solve for users with ridge regression, then swap — repeated 12 times.

      Evaluation

      • RMSE / MAE on 199,414 unseen ratings
      • Confusion matrix — “liked” (≥4★) vs predicted “liked” (≥3.5★): accuracy, precision, recall, F1, ROC-AUC
      • Top-N ranking — Precision@10, Recall@10, NDCG@10, Hit-rate@10 against Random and Popularity baselines
      • Hyper-parameter study — RMSE vs k

      Scope, limitations & future work

      🎯 Applications

      • OTT platforms (Netflix, Prime, Hotstar style “More like this”)
      • Music, books, e-commerce and course recommendation — same maths, different items
      • Personalised home-screens and email campaigns
      • Cinema / theatre programming from audience taste clusters

      ⚠️ Limitations

      • Cold-start: brand-new users / movies have no ratings (content model helps)
      • Sparsity: ~96% of the user–movie matrix is empty
      • Popularity bias: popular titles get recommended more
      • Dataset is offline and static; no real-time feedback loop

      🚀 Future scope

      • Neural collaborative filtering / autoencoders / transformers (sequence-aware)
      • Context (time, device, mood), diversity & fairness re-ranking
      • Online learning with click feedback, A/B testing
      • Real posters, trailers, multi-language support

      Local generative-AI semantic search

      Natural-language descriptions are embedded with the locally run BAAI/bge-base-en-v1.5 encoder and ranked by cosine similarity (it matches meaning rather than generating text). The model is downloaded from Hugging Face on first use and cached locally; there are no inference API calls. By default, the project embeds movie titles, genres, and keywords. To include plot summaries, provide data/movie_overviews.csv with movie_id,plot_summary columns; summaries are matched by movie ID and included in the embedding index.

      Dataset note

      The bundled dataset is synthetic (generated by generate_dataset.py with user taste clusters, movie quality and popularity long-tail) but has exactly the same shape as MovieLens-1M: 6,040 users · 3,700 movies · 1,000,209 ratings. Real MovieLens-1M files can be converted with python backend/generate_dataset.py --movielens path/to/ml-1m and the whole project retrains on them unchanged.
